# Diagramming Libraries
A repository of diagramming libraries (draw.io) used in BridgignTheGap.eu.com

- diagram_elements.drawio contains an editable version of all the elements exposed as libraries.
- Context_Mapping.xml is the library for Context Mapping diagrams including new vocabulary like Interchange Context,
- Integration_Diagrams.xml is the library for creating block diagrams for describing patterns from a structural perspective,
- Sequence_Diagrams.xml is the library for creating UML sequence diagrams for describing the behaviour of integration patterns or integration flows,
